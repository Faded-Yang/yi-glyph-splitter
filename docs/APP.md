# 桌面程序使用说明

## 安装（推荐）

双击 `YiGlyphSplit-1.0.0-Setup.exe` → 中文向导 → 完成。默认装到
`%LOCALAPPDATA%\Programs\YiGlyphSplit`（不需要管理员权限）。安装目录：

    YiGlyphSplit\
      YiGlyphSplit.exe      启动器（约 10 MB）
      runtime\              Python 运行时 + 依赖（约 286 MB）
      README-install.txt
      unins000.exe          卸载程序

开始菜单 / 桌面的「彝文切字工具」快捷方式可以直接用；卸载走「设置 → 应用」或开始菜单里的卸载项。
用户数据（`%LOCALAPPDATA%\yi-segment\`）卸载时不会删除。

**便携版**：把 `dist\YiGlyphSplit\` 整个文件夹拷走，双击里面的 `YiGlyphSplit.exe` 即可。

## 流程

1. **导入**：点「导入 TIF」（可多选）或「导入文件夹」（批量扫 *.tif / *.tiff）。
   第一次使用会让你选一个**项目目录**（存 page.json、预览图、人工修改记录），建议单独建文件夹。
2. **一键处理**：选中页（或全部）→「一键处理」。程序只在页面上**框出每个字**，不切图；约 13 s/页。
3. **规范字校验（离线，自动）**：**处理完一页会自动跑一次**，之后颜色常驻。逐框对照《规范彝文单字图形识别手册》的 5716 张标准字形打分：
   - ≥0.62 很符合规范字（**绿色实线框**）；≥0.50 明显吻合（青色）；<0.38 判为**可疑**（**红色实线框**）；
   - 右栏给出该框**最像的 3 个标准字形**（带类别编号），不认识彝文也能判断"这是不是一个字"；
   - 「下一个低分」逐个核对；颜色常驻（全为实线）。
   - **改/新建一个框会自动只重算这一框**：很标准→绿色实线，一般→青色，可疑→红色实线。
   - 右栏色板可以**手动**给单个框上色（6 种颜色 + 自动），颜色会随框保存。
   - 每页约 1 秒、完全离线、不花钱。
4. **人工复核**：拖拽/缩放/新增/删除/拆分/合并/确认/存疑；右栏 3× 细节图带上下邻字上下文；改动自动保存。
   **删框后画布不会跳到下一个框**（只换选中态），连续删框时视角不动。
5. **一键切图**：选导出目录 → 输出 001.png…、index.csv、sheet.png（按所有框，编号与画布上的编号一致）。

## 分列

- 顶栏「**分列线**」或 设置 → 显示 → 勾选「显示分列线」：每列边界显示为蓝色竖线（顶部有编号把手）。**拖分隔线**即可调整列边界，松手保存到 page.json。
- 「**重置分列**」（右栏「本页」）：丢掉手动调整，按墨迹重新自动分列。
- 自动分列会把「两列并成一列」的宽列带拆开：宽度 > 1.55×中位列宽时，在带内墨量最深的位置切一刀。
  页边的横排批注（图上方那些字）不会干扰正文分列，因为只修正过宽的列带。
- 编号与导出顺序都以当前分列为准；手动改完立刻重排。

## 编号

画布上每个框左上角有编号（000 起三位数），顺序 = **最左列 → 每列从上到下 → 下一列**，与导出文件的 `001.png…` 完全一致
（实测 522 框时画布顺序与 index.csv 的 id 序列逐项相同）。增/删/拆分/合并/拖框后立刻重排，撤销也一致。
整页适配视图下小框不显示编号（避免糊成一片），放大到约 30 px 以上或选中某个框时显示；右栏标题显示「第 N 框」。

## 快捷键

| 键 | 作用 |
|---|---|
| 滚轮 / 空格+拖动 | 缩放 / 平移 |
| 点击框 | 选中；拖动内部移动；拖动 8 个控制点缩放 |
| A 再框选 | 新建框 |
| Del | 删除选中框（不移动视角） |
| S | 以鼠标当前 y 把选中框一分为二（竖排最常用） |
| M / Shift+M | 与下一框 / 上一框合并 |
| 1 / 2 / 0 | 标为确认 / 存疑 / 复位 |
| ← / → | 上一个 / 下一个框 |
| Ctrl+Z / Ctrl+Y | 撤销 / 重做（50 步） |
| Ctrl+B / Ctrl+Shift+B | 显示/隐藏 左栏 / 右栏 |
| 拖分隔条 / 双击 | 改侧栏宽度 / 恢复默认 |

## 命令行（高级）

    "%LOCALAPPDATA%\Programs\YiGlyphSplit\YiGlyphSplit.exe" [--project D:\work\book1] [--port 8765] [--browser] [--debug]

日志：%LOCALAPPDATA%\yi-segment\logs\app.log
配置：%LOCALAPPDATA%\yi-segment\config.json（只有导出默认值与上次项目）

## 项目目录结构

    <项目>/
      project.json
      pages/<id>/
        page.json      自动分割的原始结果
        boxes.json     人工修正后的框（导出用这个）
        refcheck.json  规范字校验结果（分数 + 最像的 3 个标准字形）
        preview.png    缩略图（无框，前端画框用）
      exports/<页名>/  一键切图的产物

## 无界面 / 批量

    python tools\yi_segment.py --input <TIF或目录> --out out\batch --jobs 4 --resume

详见 docs/CLI.md。
